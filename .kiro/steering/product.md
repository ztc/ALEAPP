# ALEAPP - Android Logs Events And Protobuf Parser

ALEAPP is a digital forensics tool for parsing and analyzing Android device extractions. It processes full system extractions from Android devices (file system dumps, tar archives, zip files) and generates comprehensive HTML reports with extracted artifacts.

## Purpose
- Parse Android forensic artifacts from device extractions
- Generate HTML, TSV, KML, and timeline reports
- Support digital forensic investigations and mobile device analysis

## Key Features
- Plugin-based architecture for artifact parsing
- Multiple input formats: filesystem, tar, zip, gzip
- Profile system for selective artifact processing
- Case data management for forensic documentation
- Timeline generation for temporal analysis
- KML export for geolocation data
- LAVA integration for structured data output

## Target Users
- Digital forensic investigators
- Law enforcement analysts
- Mobile security researchers
